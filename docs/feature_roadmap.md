# Feature Roadmap

Many useful features can be built on top of the custom protocol.  These are planned to be gradually implemented after protocol is ready to be used abstractly.



## Location Tracking

Save the current location to the client every N minutes, and send them to the server in batches every M minutes (configurable). Viewi the location history on a map on clients.



## Weather Service

Get the weather information of current location and selected locations every N minutes. Send a push notification on major changes on forecast.



## Chat

Private or group chats for sending and receiving messages. Optional support for multimedia messages.



## Emergency Button

Alarm the pre-defined lists of clients on the emergency and switch to aggresively frequent location updates.



## AI Research

Submit a resarch request and an AI agent with web search access. The research is conducted asynchronously and the result is sent to client at once on completion.
